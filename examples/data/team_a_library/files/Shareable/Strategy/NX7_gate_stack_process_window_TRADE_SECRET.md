# Project OBSIDIAN - NX-7 Gate Stack Process Window (Trade Secret)

Distribution: Process Engineering leads only. Do not forward.

The NX-7 high-k gate stack uses a 1.6 nm HfZrO2 film deposited at 285 C with 42 ALD cycles, followed by a 950 C spike anneal in a 2% O2 ambient. The work-function metal is a 3.2 nm TiAlC layer. This combination gives the 18 mV threshold-voltage advantage over competing processes and is the core of the NX-7 cost model.
